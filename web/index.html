NO PYTHON · NO LOCALHOST SERVER · NO SHARED DATABASE

Set up once. Study anywhere you have your file.

  1. Download the extension ZIP and extract it.
  2. In Chrome open chrome://extensions, or in Edge open edge://extensions. Enable Developer mode, choose Load unpacked, and select the extracted Studyspace-Extension folder containing manifest.json.
  3. Click the Studyspace extension icon. Sign into MUJ in the same browser profile, then choose Find my subjects.
  4. Choose your semester, enter your Gemini key and select Fetch & analyze semester. Lab subjects are skipped. Keep the extension tab open.
  5. Choose Save study JSON. Open that file here for summaries, quizzes, flashcards, videos and your exam plan.

Test edition: installation is manual; it is not yet in an extension store. MUJ may restrict direct API access. If the university requires an approved application, the extension will report that rather than bypass access controls.

Your work stays in your file.

Opening a saved file here does not upload it. Notes, plans and topic progress live in the JSON you save. Keep a backup and save again after making changes.

Privacy & permissions →

Use your own Google keys.

Analysis sends notes to Gemini. Optional video search uses YouTube Data API v3. The extension keeps keys in memory for the current tab; they are excluded from exports.

No Studyspace hosting subscription. Google quotas and any API charges still apply.
