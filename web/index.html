Download for Windows ↓

Test edition · v0.1.1 · One ZIP for both platforms

Chrome 120+ or a current Edge release. The extension is not available for Safari, Firefox or mobile browsers.

  1. Extract your extension.

    Right-click the downloaded ZIP → Extract All. Move the extracted folder somewhere permanent, such as Documents.

  2. Add it to your browser.

    Open chrome://extensions or edge://extensions. Enable Developer mode, choose Load unpacked, then select the Studyspace-Extension folder containing manifest.json.

  3. Connect. Analyze. Save.

    Click the extension icon, sign into MUJ in the same browser profile, and choose your semester. Enter your Gemini key, fetch your notes, then Save study JSON.

  1. Unzip in Finder.

    Double-click the downloaded ZIP. Move the extracted Studyspace-Extension folder into Documents so it stays available.

  2. Load in Chrome or Edge.

    Open chrome://extensions or edge://extensions. Enable Developer mode → Load unpacked. In Finder, choose the folder containing manifest.json. Use Chrome or Edge rather than Safari.

  3. Make your semester yours.

    Click the extension icon and sign into MUJ in that browser profile. Choose your semester, enter your Gemini key, and fetch your notes. Keep the tab open, then Save study JSON.

A FEW THINGS TO KNOW

Before you dive in.

Is Studyspace free to use?

There is no Studyspace hosting subscription for this workflow. You supply your own Google keys; their quotas and any API charges still apply. No API keys are bundled in the download.

Does this work on both Windows and Mac?

Yes, the browser extension uses the same code and ZIP for Chrome and Edge on both operating systems. There is no .exe or .dmg to install. It is a test extension installed manually through Developer mode. A native Safari extension is not included.

Where do I get my API keys?

Create a Gemini key in Google AI Studio ↗. For optional videos, enable YouTube Data API v3 in your Google Cloud project, then create an API key under APIs & Services → Credentials and restrict it to that API.

Will it definitely connect to my MUJ account?

You must be signed into MUJ in the same browser profile. MUJ can restrict direct API access; a 401/403 may require re-login or a university-approved integration. The extension reports these errors and cannot bypass access controls.

What files can I study?

PDF, PPTX, DOCX, TXT and MD, up to 50 MB per file. Export older DOC/PPT files and complex Office diagrams to PDF. The browser viewer opens the study JSON saved by the extension, not the original PDF.
