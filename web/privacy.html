What the test extension accesses

Only after you grant optional host permissions, the extension reads your own enrolled subjects and permitted attachments at mujlms.manipal.edu using your existing browser session. It does not ask for your password or read browser history. Lab subjects are excluded.

When you choose analysis, note content is sent directly to Google Gemini with your key, subject to Google's API terms, retention and billing. Large PDFs use Google's Files API; the extension attempts deletion after analysis. If deletion fails, a warning appears. Google documents automatic expiry for Files API uploads.

Optional YouTube search sends subject/topic queries to Google; candidate metadata and topic concepts go to Gemini for ranking. It does not send your full PDF to YouTube. Video recommendations are based on metadata, not watched content.

What is stored

Keys exist only in the extension tab's memory until it closes. They are not stored in browser extension storage, a shared server or exported study JSON. Original notes are buffered temporarily; saving originals to Downloads is optional. The study JSON contains subjects, summaries, topics, quizzes, flashcards, video recommendations, progress and plans. Treat it as a personal academic document.

The website viewer reads the JSON locally in your browser and makes no API calls. It does not automatically save your changes. Download a new JSON file and keep backups. Website hosting may record ordinary page-access logs; the study file's contents are not sent to the host.

Permissions and limits

The downloads permission saves your requested files. Optional host access is restricted to MUJ LMS, Google's Gemini endpoint and Google's YouTube API endpoint. There is no externally connected website bridge, remote executable code or native helper.

This is an independent, unofficial test tool, not endorsed by MUJ or Google. It respects your existing access. If MUJ blocks direct API requests, an approved university integration or manual file export is needed. PDF/PPTX/DOCX/TXT/MD are supported up to 50 MB per file; Office vector diagrams and layout may be incomplete.
